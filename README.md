# cpp-rmrs-wave-loads

Тестовое задание: проверка применимости Правил РМРС и расчёт волновых нагрузок корпуса

Программа с графическим интерфейсом, которая:

1. проверяет, попадает ли судно под действие Правил РМРС согласно требованиям
   **п. 1.4.1.1 и 1.4.1.2** Правил классификации и постройки морских судов,
   часть II "Корпус";
2. выполняет расчёт **волновых изгибающих моментов и перерезывающих сил**
   согласно **п. 1.4.4** тех же Правил

Нормативная база: НД 2-020101-174 / 2-020101-174-E
"Правила классификации и постройки морских судов", часть II "Корпус",
глава 1.4 "Продольная прочность", редакция в силе с 01.01.2026
(сайт РМРС `rs-class.org`)

## Что делает программа

Пользователь вводит главные размерения и характеристики судна
(`L`, `B`, `D`, `Cb`, `v0`, район плавания, тип судна). Программа:

- **определяет область распространения** (п. 1.4.1.1) и выдаёт один из вердиктов:
  - судно **не подпадает** под главу 1.4
  - судно подпадает, но требуется **прямой расчёт прочности** (п. 1.4.1.2)
  - судно подпадает, **применимы формулы** п. 1.4.4
- **строит эпюры** волнового изгибающего момента `Mw` (перегиб/прогиб) и
  перерезывающей силы `Nw` (положительная/отрицательная) по всей длине судна.
  На графике - заливка до нулевой линии, характерные сечения `0 / 0,2L / 0,4L / 0,65L / L`
  и подсказка со значениями при наведении курсора

## Реализованные формулы

### Область распространения (п. 1.4.1.1)

- неограниченный район, R0, R1, R2 -> `L >= 65 м`; RSN/R3 -> `L >= 60 м`
- стальное судно сварной конструкции, `L <= 350 м` (п. 1.1.1.1)
- контейнеровозы неограниченного района `L >= 90 м` - вне главы 1.4 (часть XVIII)
- суда с широким раскрытием палубы и суда технического флота остаются в главе 1.4,
  но программа напоминает о дополнительных требованиях 3.1 и 3.6

### Прямой расчёт прочности (п. 1.4.1.2)

Требуется, если верно хотя бы одно:

- `L/B <= 5`
- `B/D >= 2,5` (для R2, R2-RSN, R2-RSN(4,5), R3-RSN и R3 порог `B/D >= 4,0`)
- `Cb < 0,6`
- `v0 > v`, где `v = k * sqrt(L)` (формула 1.4.1.2.3), `k = 2,2` при `L <= 100 м`;
  `k = 2,2 - 0,25 * (L - 100)/100` при `L > 100 м`
- судно перевозит грузы при высокой температуре либо имеет необычную
  конструкцию/назначение

### Волновой коэффициент (п. 1.3.1.4)

```
cw = 0,0856 * L                      при L <= 90 м
cw = 10,75 - ((300 - L)/100)^1,5      при 90 < L < 300 м
cw = 10,75                           при 300 <= L <= 350 м
```

### Волновой изгибающий момент Mw, кН*м (п. 1.4.4.1)

```
перегиб (hogging):  Mw = +190 * cw * B * L^2 * Cb * alpha * 10^-3
прогиб  (sagging):  Mw = -110 * cw * B * L^2 * (Cb + 0,7) * alpha * 10^-3
```

`alpha` - коэффициент распределения по длине (табл. 1.4.4.1, в Правилах обозначен α):

```
alpha = 2,5 * (x/L)          при x/L < 0,4
alpha = 1                    при 0,4 <= x/L <= 0,65
alpha = (1 - x/L)/0,35       при x/L > 0,65
```

### Волновая перерезывающая сила Nw, кН (п. 1.4.4.2)

```
положительная:  Nw = +30 * cw * B * L * (Cb + 0,7) * f1 * 10^-2
отрицательная:  Nw = -30 * cw * B * L * (Cb + 0,7) * f2 * 10^-2
```

`f1`, `f2` - коэффициенты распределения (табл. 1.4.4.2), вспомогательный
коэффициент `f0 = 190 * Cb / (110 * (Cb + 0,7))`

Здесь `x` - отстояние сечения от кормового перпендикуляра, м; `Cb` в формулах
1.4.4 принимается не менее 0,6

### Ограниченные районы (п. 1.4.4.3)

Для ограниченных районов при `60 м <= L <= 150 м` результат домножается на
редукционный коэффициент `phi` (табл. 1.4.4.3, зависит от района и `L`;
для R0 `phi = 0,9`). Вне этого диапазона `phi = 1`

> **Упрощение:** дополнительные множители `psi` и `v` (п. 1.4.4.3), учитывающие
> геометрию носовой оконечности (угол beta0, коэффициент полноты ватерлинии,
> развал бортов), приняты равными 1. Они относятся к судам ограниченного
> района длиной 60...150 м и требуют данных, выходящих за рамки основного ввода

## Архитектура

```
src/core/                    чистый C++ без зависимостей от GUI (тестируемое ядро)
  NavigationArea.h           районы плавания
  ShipType.h                 типы судов
  ShipParameters.h           модель исходных данных
  ApplicabilityChecker.*     проверка п. 1.4.1.1 и 1.4.1.2
  WaveLoadCalculator.*       расчёт п. 1.4.4
src/app/main.cpp             графический интерфейс (Dear ImGui + GLFW + OpenGL3)
tests/core_tests.cpp         юнит-тесты ядра (doctest)
```

Ядро (`strength_core`) не знает ничего об интерфейсе - это разделяет
ответственность (SRP) и позволяет покрыть всю расчётную логику тестами

## Сборка

Требуется CMake >= 3.16, компилятор с C++17 и доступ в интернет при первой
конфигурации (CMake сам скачает Dear ImGui, GLFW и doctest через FetchContent)

```powershell
cmake -S . -B build
cmake --build build --config Release
```

Запуск приложения:

```powershell
.\build\Release\rmrs_gui.exe
```

Запуск тестов:

```powershell
.\build\Release\core_tests.exe
# или через CTest:
ctest --test-dir build -C Release
```

## Стек и зависимости

- **Dear ImGui** - графический интерфейс
- **GLFW** - окно и контекст OpenGL
- **OpenGL 3** - отрисовка
- **doctest** - юнит-тесты

Все зависимости подключаются автоматически через `FetchContent` - вручную
ставить ничего не нужно
